Easy Blog Management

How to Add Your Own Blog

Follow these simple steps whenever you want to publish another article.

1. Create Your Blog Page

Create a new HTML file in your repository. For example, if your article is about AI chatbots, you can create:

blog-new-ai-chatbot.html

2. Write Your Article

Add your article content inside the new HTML page. You can include headings, paragraphs, images, lists, links and other useful information.

<h1>Your Blog Title</h1> <p> Write your article content here... </p>

3. Add a Blog Card

Copy an existing blog card from this page and change the title, description, category and link.

<a href="blog-new-ai-chatbot.html"> Read Article → </a>

4. Push Changes to GitHub

After adding your new article and blog card, save the files and push the changes to your GitHub repository. Vercel can then deploy the updated website.

blog.html + blog-new-ai-chatbot.html
